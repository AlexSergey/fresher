Fresher is free and open source. Its code and every release live at github.com/AlexSergey/fresher.

{{kind-count}} kinds of files, each with its risk

Every kind has a page: what it is, which app made it, what happens if it goes. There is no "Other": what Fresher does not recognize is shown as its real folders.

You see everything before anything goes

Scanning only reads. Before a cleanup you see the exact items, their size and the highest danger among them. Each item is checked again right before it goes, and anything that changed is skipped.

  • Items go to the Trash; the Cleanups screen puts them back.
  • A permanent delete is a separate tick, every time.
  • System folders and other users' files are never touched.

What it holds to

01

Knows a developer’s Mac

Xcode data, old IDE versions, package caches, builds of projects untouched for a year, unused toolchains, local AI models.

02

Private

The app makes no network requests: no telemetry, no analytics, no crash reports, no update checks.

03

Nothing in the background

No helper, no login item, no scheduled scans. Opening the app starts nothing.

04

Plain English

Every kind of file says what it is, what made it, and whether it comes back.

05

Undoable

The Trash first, Put Back from the app. It never empties the Trash for you.

06

Never an administrator

It never asks for administrator rights and never removes what it cannot name.

Install

Download the disk image, open it and drag Fresher to Applications. Apple silicon and Intel, macOS 13 or later.

Get it only from here

Fresher is published only on getfresher.app and its GitHub releases. It is free: a copy that asks for money came from somewhere else.

Fresher itself never asks for your password or for administrator rights. A copy that does is not Fresher: delete it.

The first launch

  1. Open Fresher once; macOS says it cannot verify it.
  2. System Settings → Privacy & Security → "Open Anyway".
  3. macOS asks for your password to confirm. After that it opens normally.
