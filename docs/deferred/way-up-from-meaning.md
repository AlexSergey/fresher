# A way up from a folder opened from the by-meaning view

**Agreed:** 2026-11-17, by delegation (plan [012](../plans/012-storage-map/readme.md), 04/05) · **Due at:** with the
next change to the overview

## What is postponed

A folder opened from a row of the by-meaning view shows its place view with a breadcrumb that starts at that folder:
there is no step above it, only back to the by-meaning view.

## What doing it needs

The way from the volume's root down to the folder, kept in the navigation as when a folder is opened from the by-place
view (the core's `Descent::Stay` reopens each step), or the folder's ancestors asked of the core.
