# A setting for the default removal

**Agreed:** 2026-11-16, delegated to the agent by the user (plan 005, decision 8) · **Due at:** when the user asks
for it

## What is postponed

The draft of plan 005 listed "the default removal (Trash, or permanent — still confirmed)" in the General group. It is
not built: rule 2 makes a permanent delete a separate, explicit choice, and a setting that pre-selects it in the
confirmation would make that choice a default.

## What doing it needs

The user's decision that a pre-selected permanent delete is still explicit enough. If so: a core choice setting read
only by the confirmation dialog to pre-select the method; the confirmation still shows the permanent sentence and asks
for its own consent (`PermanentConsent`) every time.
