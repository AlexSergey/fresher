# Fresher 0.1.0

Fresher is a free, open-source disk cleaner for macOS. It shows where your disk space went, explains every kind of
file in plain English with what removing it costs, and removes only what you confirm.

**0.1.0 is the first release, for testers.** It has been built carefully and tested on fake file trees, but not yet by
many people on real Macs. Please try it, and tell us when it gets something wrong.

What is in it: the [changelog](https://github.com/AlexSergey/fresher/blob/main/docs/changelog.md#010---2026-11-25).

## Supported Macs

macOS 13 Ventura or later, on Apple silicon or Intel: the one download holds both.

## Install

1. Download `Fresher_0.1.0_universal.dmg` from the assets below.
2. Open it and drag Fresher to the Applications folder.
3. Eject the disk image.

## First launch

This release is not signed with an Apple Developer ID and not notarized yet, so macOS stops the first launch of a
downloaded copy. To allow it:

1. Open Fresher from Applications once. macOS says it cannot verify the app; close the message with Done (or Cancel
   on macOS 13 and 14), not Move to Trash.
2. Open System Settings → Privacy & Security and scroll down to Security.
3. Click "Open Anyway" next to the line about Fresher, and confirm with your password or Touch ID.

After that Fresher opens normally. Each new version you download asks for this once again.

## Full Disk Access

Fresher works without any permission and tells you which folders it could not see. Some folders, such as Mail's and
Safari's data, macOS shows only to apps you allow. When a scan misses them, Fresher says so and offers Open System
Settings: turn on Fresher in the Full Disk Access list, come back and scan again. Fresher still reads only names and
sizes, never the contents of your files, and nothing leaves your Mac.

**After an update** macOS treats the new version as a different app until Fresher is signed, so its Full Disk Access
is off again. In System Settings → Privacy & Security → Full Disk Access, remove Fresher from the list with the minus
button and turn it on again when Fresher asks.

## Check your download

Each release lists the checksum of its disk image in `SHA256SUMS`, and GitHub keeps a signed record of the build that
made it. With both files in one folder:

```bash
shasum -a 256 -c SHA256SUMS
```

It prints `Fresher_0.1.0_universal.dmg: OK`. With the GitHub command-line tool you can also check that the image was
built by this repository's release workflow:

```bash
gh attestation verify Fresher_0.1.0_universal.dmg --repo AlexSergey/fresher
```

## No warranty

Before your first cleanup Fresher asks you to accept these five lines:

- Fresher is free and open source, and it comes with no warranty.
- It removes only what you confirm, so each removal is your decision.
- A danger level is Fresher's best judgement, not a guarantee.
- Keep a backup of anything you cannot afford to lose.
- Items go to the Trash, where you can put them back until the Trash is emptied. A permanent delete, and what an app's
  own tool removes, cannot be undone.

## Tell us what went wrong

- Something offered that should have been left alone:
  [report a wrong finding](https://github.com/AlexSergey/fresher/issues/new?template=wrong-finding.yml).
- A folder Fresher should know:
  [suggest a missing folder](https://github.com/AlexSergey/fresher/issues/new?template=missing-folder.yml).
- Anything else that broke: [report a bug](https://github.com/AlexSergey/fresher/issues/new?template=bug-report.yml).
- Anything that removes a file you did not confirm, reaches outside the scanned folders or sends anything over the
  network is a security problem: report it privately, as
  [the security policy](https://github.com/AlexSergey/fresher/blob/main/.github/SECURITY.md) says.

Write your user name in any path as `~`.
