# 032/01/01 — The type, the sink, the event and the engine

**Status:** 🔨 awaiting the user's walk · **Version:** 0.1.0 · **Date:** 2026-11-22 · **Modules:** core, engine, app, app/ui

Read first: `CLAUDE.md`, `docs/rules.md`, [`../00-design.md`](../00-design.md) section 1, `crates/core/src/module.rs`
(`FindingSink`), `crates/core/src/event.rs` (`ModuleFinished`), `crates/core/src/removal.rs` (`ToolCommand::forces`),
`crates/engine/src/session.rs` (`ModuleSink`, `Output::module_finished`), `app/ui/src/state/reduce.ts`.

A module can describe space it never offers. This step adds the core type, the sink's method, the event's field, the
engine's collection and the UI's state. No module uses it yet; no screen shows it yet (plan 03).

## Files

- `crates/core/src/insight.rs` (new), re-exported from `lib.rs`: `Insight`, `Figure`, `InsightPart`, `ShownCommand`,
  `InsightError`, `MAX_FIGURES` (4), `MAX_INSIGHT_PARTS` (8), `MAX_NOTES` (4). All `Clone, Debug, PartialEq, Eq,
  Serialize, TS` (`#[ts(export)]` as the other IPC types are exported; `#[serde(rename_all = "camelCase")]`).
  - `Figure { pub label: Text, pub size: ByteSize }`.
  - `InsightPart { pub label: Text, pub size: ByteSize, pub detail: Text, pub effect: Text, pub danger: DangerLevel,
    pub command: Option<ShownCommand> }`.
  - `ShownCommand { tool: ToolId, args: Vec<String>, line: String }` with `ShownCommand::new(tool: ToolId, args:
    Vec<String>) -> Result<Self, InsightError>` and getters `tool()`, `args()`, `line()`. `line` is the tool's id and
    the arguments joined by single spaces (`docker --context orbstack builder prune --all`). Refused: no argument
    (`InsightError::NoArguments`); an argument that is empty or holds a character outside ASCII letters, digits and
    `. _ / : = @ + -` (`InsightError::NeedsQuoting { arg }`); a forcing command (`InsightError::Forced { arg }`: build
    the same `ToolCommand` and ask `forces()`, never a second copy of that rule). Serialized with `line` so the UI shows
    and copies it as the core built it.
  - `Insight { identity: String, title: Text, summary: Text, figures: Vec<Figure>, parts: Vec<InsightPart>, notes:
    Vec<Text> }` with `Insight::new(identity: &str, title: Text, summary: Text, figures: Vec<Figure>, parts:
    Vec<InsightPart>, notes: Vec<Text>) -> Result<Self, InsightError>` and getters. Refused: an identity that is not
    kebab case (`InsightError::Identity { identity }`, `ids::is_kebab_case`); more than `MAX_FIGURES` figures, parts or
    notes over their maximum (`TooManyFigures`, `TooManyParts`, `TooManyNotes`, each with the count).
  - A doc comment on `Insight`: what a module describes and never offers; never selectable, never counted in a total,
    never stored or cached; a restore describes again.
- `crates/core/src/module.rs` — `FindingSink::describe(&mut self, insight: Insight)` with a default body that drops it
  (doc: "Space the module describes and never offers; a sink that keeps findings only drops it."), so every existing
  sink compiles unchanged.
- `crates/core/src/event.rs` — `Event::ModuleFinished` gains `insights: Vec<Insight>` after `left_out`, with a doc
  comment ("What the module described and does not offer, in the order it gave it."). Update every literal of
  `ModuleFinished` in the workspace (engine tests, `crates/e2e/tests/*_home/mod.rs`, `crates/e2e/tests/downloads.rs`,
  `app/tauri/src/dev_runs/run.rs`, `app/tauri/tests/sandboxes/harness.rs`): patterns with `..` need nothing.
- `crates/engine/src/session.rs` — `Output` keeps one `Vec<Insight>` per planned module, beside `left_outs`;
  `ModuleSink::describe` pushes into the module's list unless an insight with the same identity is already there (then
  `tracing::warn!` with the module and the identity, and the new one is dropped); `module_finished` takes the list and
  sends it in the event, whatever the outcome (an insight given before a failure or a cancel is still sent).
- `crates/engine/src/insight_tests.rs` (new, `#[cfg(test)] mod insight_tests;` in `lib.rs`, in the shape of
  `left_out_tests.rs`) — the engine's tests below.
- `app/ui/src/ipc/bindings.generated.ts` — regenerated by the bindings test (`app/tauri/tests/bindings.rs`), never by
  hand.
- `app/ui/src/state/reduce.ts` — `CoreState.modules` entries gain `readonly insights: readonly Insight[]`, filled from
  the event. Every TS literal of a `module-finished` event gains `insights: []` (`app/ui/src/test/*-scan.ts`,
  `reduce.test.ts`, `left-out-only.test.tsx`, `category-screen.test.tsx`, `app/ui/src/ipc/mock.ts`,
  `app/ui/e2e/core-mock.ts`, wherever the compiler names one).
