# 043/01/02 — `flags.toml` and the build script

**Status:** ✔️ done · **Version:** 0.2.0 · **Date:** 2026-11-26 · **Modules:** app/tauri, sandbox, repo, docs

The file at the root, the build script that reads it (and `FRESHER_FLAGS`) into `FLAGS`, and the composition reading
`high` from it. Values stay `withheld` / `hidden`, so nothing a person sees changes. The design:
[`../00-design.md`](../00-design.md), sections 1, 3 and 4; agent's calls 2 and 3.

## Read first

01/01's commit; `app/tauri/build.rs`, `app/tauri/Cargo.toml`; `app/tauri/src/compose.rs` (`normal`, `Shared`,
`assemble`, the compose tests, `own_build`); `app/tauri/src/sandbox.rs` (`SandboxMode::new`, `from_env`,
`offering_high`, its tests); `app/tauri/src/lib.rs` (the modules); `docs/dependencies.md` (the `toml` row, "Build and
checks only"); `docs/architecture/README.md`, "The High switch".

## Files

- `flags.toml` (new, at the root) — exactly the design's example, section 1: `[high]` and `[largest]`, each with
  `about`, `type`, `values`, `release`, `development`; values `withheld` and `hidden` in both columns.
- `app/tauri/build/flags.rs` (new) — `pub(crate) enum Profile { Release, Development }`; `pub(crate) struct Resolved
  { name, type_name, value }`; `pub(crate) enum FlagsError` (one variant per refusal of the design, section 3, each
  naming the flag and the key or the override's item; `impl Display` and `std::error::Error` by hand); `pub(crate) fn
  resolve(file: &str, profile: Profile, overrides: Option<&str>) -> Result<Vec<Resolved>, FlagsError>` (flags in the
  order of their names); `pub(crate) fn render(flags: &[Resolved]) -> String` (the generated literal of the design, PascalCase
  variants, `fresher_core::` paths). No `unwrap`, no `panic!`.
- `app/tauri/build.rs` — `#[path = "build/flags.rs"] mod flags;`; before `tauri_build`: the three `cargo:rerun-if-*`
  lines, the profile from `CARGO_CFG_DEBUG_ASSERTIONS`, `FRESHER_FLAGS` from the environment, `resolve` then `render`
  written to `$OUT_DIR/flags.rs`. Its module doc gains one line: it also makes the build's flags.
- `app/tauri/Cargo.toml` — `toml.workspace = true` under `[build-dependencies]` and `[dev-dependencies]`.
- `app/tauri/src/flags.rs` (new) — doc comment (what a build ships with; the source is `flags.toml`; nothing reads it
  at runtime), then `include!(concat!(env!("OUT_DIR"), "/flags.rs"));`.
- `app/tauri/src/lib.rs` — `mod flags;`; `#[cfg(test)] #[path = "../build/flags.rs"] mod build_flags;` (its tests
  live at the end of `build/flags.rs` in the project's `mod tests { mod negative {} mod positive {} }` form, under
  `#[cfg(test)]`, so the build script compiles without them).
- `app/tauri/src/compose.rs` — `normal` sets `high: crate::flags::FLAGS.high`; the comment: "the build's `high`
  flag (`flags.toml`)". The test `the_normal_engine_withholds_high` (if named so) becomes
  `the_normal_engine_follows_the_high_flag`, asserting `engine.high_level() == FLAGS.high`.
- `app/tauri/src/sandbox.rs` — `new` and `from_env` start from `FLAGS.high`; its doc and test
  `sandbox_mode_withholds_high_by_default` become `sandbox_mode_follows_the_high_flag`; `offering_high_offers_it`
  stays.
- `Cargo.lock` (regenerated by the build).
- `docs/dependencies.md` — the `toml` row's "Used by" gains `app (its build script and the script's tests)`.
- `docs/architecture/README.md` — a bullet "The build's flags" before "The High switch": `flags.toml`, the build
  script, `FLAGS`, the override, the refusals, that nothing reads it at runtime; "The High switch" says the app sets
  it from `FLAGS.high`.

## Interfaces produced

- `crate::flags::FLAGS: BuildFlags` in `fresher-app`; `build/flags.rs`'s `resolve` and `render` (read again by the
  guard's design in 02/03, which follows the same rules).

## Tests (negatives first)

`app/tauri/build/flags.rs`, `mod negative`:
- `a_file_that_is_not_toml_is_refused`
- `a_table_missing_a_key_is_refused` (each of the five keys in turn)
- `a_table_with_another_key_is_refused`
- `an_empty_about_is_refused`
- `fewer_than_two_values_or_a_repeated_one_is_refused`
- `a_value_that_is_not_kebab_case_is_refused`
- `a_release_or_development_value_outside_its_values_is_refused`
- `an_override_naming_an_unknown_flag_is_refused`
- `an_override_with_a_value_outside_its_values_is_refused`
- `an_override_naming_a_flag_twice_or_without_an_equals_sign_is_refused`

`mod positive`:
- `a_release_build_takes_the_release_column`
- `a_development_build_takes_the_development_column`
- `an_override_replaces_only_the_flags_it_names` (`" largest = shown "` with spaces)
- `an_empty_override_changes_nothing`
- `render_writes_each_value_as_its_pascal_case_variant` (`withheld` → `Withheld`, a two-word value `only-safe` →
  `OnlySafe`)
- `the_repository_file_resolves_for_both_profiles` (reads `../../flags.toml` through `CARGO_MANIFEST_DIR`)

`compose.rs` and `sandbox.rs`: the renamed tests above (value-agnostic, so plan 03 changes no Rust test).
