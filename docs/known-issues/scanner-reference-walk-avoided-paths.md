# The reference walk and the scanner compare avoided paths differently

**Status:** open · **Updated:** 2026-11-18

## Symptom

`NaiveWalk` (the reference walk of the property tests) compares an avoided path as given, the scanner compares it in
its canonical form. An avoided path that goes through a symlinked folder makes the two walks disagree on the entries
they report. The property tests of plan 019/01/02 avoid only paths that are their own canonical form.

## Cause

`walk/boundary.rs` canonicalizes the avoid list; `crates/testing/src/naive_walk.rs` does not.

## What was tried

- Found while writing the property test for the places seen: the first run shrank to a `Library` that is a link to
  `a`, avoiding `Library/Caches`. The test generators were narrowed; the reference walk was left alone.

## Options left

- Canonicalize the avoided paths in `NaiveWalk` the same way, and let the generators produce links again.
- Accept it: a symlinked folder on the way to an avoided place is not generated by any test today, and the scanner's
  behaviour is the safe one.
